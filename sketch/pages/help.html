Frequently asked

Common questions about providers, combos, and routing.

How does failover between providers work?

When a combo has multiple targets, ExoRoute tries them in priority order. On retryable errors (429, 5xx, timeouts) it moves to the next target. Non-retryable errors like 400 stop immediately. See Errors & retries.

Are my provider API keys stored securely?

Keys are stored in the local LMDB environment under ~/.exoroute, never sent to the browser after creation, and masked everywhere in the UI. The database file is owned by a single ExoRoute process — keep it on local disk only.

What happens when a provider quota runs out?

The circuit breaker trips for that provider, combos reroute to healthy targets automatically, and you'll see the provider marked on the Quota page. Once quota resets or you top up, the breaker half-opens and traffic resumes.

Can I use a different protocol upstream?

Yes — ExoRoute translates between OpenAI and Anthropic formats. Set the provider type to Anthropic or OpenAI-compatible, and clients can keep using whichever format they prefer.

Why did a request return 429?

Either the client API key hit its rate limit, or all combo targets are quota-limited/circuit-broken. Check the Requests page — each row shows which provider and target were tried.

How do I back up my configuration?

Use Backup now under Settings → Data & backup for a snapshot, or Export data for a portable JSON of providers and combos.
