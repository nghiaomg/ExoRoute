Quickstart

5 min

Point any OpenAI-compatible client at the gateway. ExoRoute routes to your configured providers.

curl 
curl http://127.0.0.1:8686/v1/chat/completions \
  -H "Authorization: Bearer exr_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "Hello"}],
    "stream": true
  }'
1 · Create a keyUse API keys — the secret is shown once.
2 · Add a providerConfigure upstream credentials under Providers.
3 · Build a comboOrder providers into a combo with failover rules.

Authentication

All gateway endpoints require a client API key in the Authorization header.

Keys never leave this machine. Provider credentials are stored encrypted-at-rest in LMDB and are never exposed through the API.
HeaderFormatNotes
AuthorizationBearer exr_…Client API key from API keys page
X-Exo-Combocombo-nameOptional — force a specific combo
X-Exo-Request-IduuidOptional — idempotency / tracing

python · openai sdk 
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8686/v1",
    api_key="exr_your_key",
)

resp = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Hi"}],
)
print(resp.choices[0].message.content)

Streaming (SSE)

Set "stream": true. ExoRoute translates between OpenAI and Anthropic SSE formats automatically.

  • First event is data: {"choices":[…],"usage":null} role delta.
  • Usage stats arrive in a final chunk before data: [DONE].
  • If a provider drops mid-stream, ExoRoute can transparently retry the next target — already-sent tokens are not replayed.
  • Client disconnect cancels upstream work and releases the request slot.

Errors & retries

Important

ExoRoute only retries requests it can prove were not accepted upstream.

StatusMeaningRetryable?
400Bad request — fix payloadNo
401/403Invalid API keyNo
429Rate limited or quota exhaustedYes — next combo target
500/502/503Upstream failure before responseYes
504Upstream timeoutYes

Every response includes X-Exo-Provider and X-Exo-Attempts headers showing which upstream served the request and how many tries it took.

Rate limits

Limits are per-API-key and per-provider concurrency, configured under Settings and each provider's routing card.

429 responses include Retry-After. ExoRoute honors upstream hints and applies jittered exponential backoff on retries.
